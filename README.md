🏧 ATM Simulator

A simple ATM Simulator built using Python.

This project simulates basic ATM operations such as PIN verification, checking balance, depositing money, and withdrawing money.

🚀 Features

- 🔐 PIN verification
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- ⚠️ Insufficient balance checking
- 🔢 Limited PIN attempts
- 🚪 Exit option
- 🖥️ Simple command-line interface

🛠️ Technologies Used

- Python 3
- No external libraries required

🔑 Default PIN

For demonstration purposes, the default PIN is:

1234

💰 Starting Balance

The starting balance is:

₹5000
